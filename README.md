# sweater_pattern_generator
Main Idea: I want an easy way to make sweaters and I don't wanna do the math by hand

Background: I have been knitting for the past 10 years, and I struggle to find patterns for the yarn I buy or already have on hand. I also graduated with a B.S. in Computer Information Systems, and want to combine my hobbies with what I learned in college. I also am interested in the connection between fiber arts and computer programming 
(I <3 Ada Lovelace).

Goal: Create a program that uses pre-set sweater patterns to generate a customized pattern based on the user's desired garment size and the gauge of the yarn they are using. This can help the user get stash-bust their yarn by creating patterns specifically for the yarn they have on hand, rather than trying to find a pattern that uses that specific yarn or gauge. 

Notes
- Patterns are for very basic sweater structures and designed by myself. I am not using someone else's patterns, free or paid, to create these patterns. I am in the process of creating a sweater of my own design, and will have to workshop my patterns as I go.
- I hope to expand the pattern database once the base program is working

Future Goals
- Add feature that calculates the amound of yarn needed based off the gauge, pattern, and size
- Add more patterns to the database (scarves, hats, etc)
- Add some sort of colorwork feature using open-source pixel art patterns available online
